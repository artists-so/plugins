# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: participation here is harassment-free for everyone, regardless of
who they are. Be direct about the work, generous with the people doing it.
Trolling, insults, doxxing, and sustained disruption are not tolerated.

Reports: open an issue if it can be public, or contact the maintainers through
the [artists-so org profile](https://github.com/artists-so) if it cannot.
Maintainers will act on reports and explain moderation decisions where
appropriate. Enforcement follows the Covenant's
[community impact guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
