# What the tools answer with

Generated by `bun run samples` against the synthetic fixture in `test/fixture.ts`,
through the same handlers the Executor runtime calls. Do not edit by hand.

Uuids and paths are elided. The fixture defines the labels `DAWN` and `DAY` and
the statuses `PLANNED` and `DRAFTED`; a real project defines its own.

The outline referred to below as `OUTLINE`:

```ts
const OUTLINE = [
  {
    "title": "Act I",
    "type": "Folder",
    "children": [
      {
        "title": "The arrival",
        "type": "Text",
        "label": "DAWN",
        "status": "DRAFTED",
        "synopsis": "He wakes before the alarm he did not set.",
        "content": "The first line.\n\nThe second, after a break."
      },
      {
        "title": "The lockout",
        "type": "Text",
        "label": "DAY",
        "status": "PLANNED"
      }
    ]
  }
];
```

### Reading a project: its shape, and the vocabularies it defines

```ts
await tools.scrivener_native.binder_read({ path, as: "text" });
```

```json
{
  "labels": [
    "No Track",
    "DAWN",
    "DAY"
  ],
  "statuses": [
    "No Status",
    "PLANNED",
    "DRAFTED"
  ],
  "outline": "Manuscript\n  Act I\nFront Matter\n  Copyright\nResearch\nTrash"
}
```

### Reading a document back

```ts
await tools.scrivener_native.document_read({ path, id: "<uuid>" });
```

```json
{
  "id": "<uuid>",
  "text": "The first line.\n\nThe second, after a break.",
  "synopsis": "He wakes before the alarm he did not set.",
  "words": 8
}
```

## Refusals

A refusal arrives as **data** — `{ refused, message }`, and nothing that could be
mistaken for a result. A thrown error would reach the caller as an opaque
`Internal tool error [<id>]` with the reason left behind in the daemon log, which
is no use to whoever has to decide what to do next. Check for `refused` before
reading a result.

### An id the binder does not contain

```ts
await tools.scrivener_native.document_read({ path, id: "<uuid>" });
```

```json
{
  "refused": "item-missing",
  "message": "No binder item with id <uuid>. Call binder_read to see the ids this project has."
}
```

### A label the project does not define

```ts
await tools.scrivener_native.binder_sync({ path, outline: [{title: "Bad", label: "DUSK"}], force: true });
```

```json
{
  "refused": "unknown-vocabulary",
  "message": "Unknown label \"DUSK\". Define it in the project first (Project ▸ Settings). Known: No Track, DAWN, DAY"
}
```

### A path that is not a Scrivener project

```ts
await tools.scrivener_native.binder_read({ path: "/tmp/Not-a-project.scriv" });
```

```json
{
  "refused": "project-unreadable",
  "message": "Nothing readable at /tmp/Not-a-project.scriv. Give the path of the .scriv package itself (the folder, not the .scrivx inside it)."
}
```

### The project is open somewhere else (here: a lock file)

```ts
await tools.scrivener_native.document_write({ path, id: "<uuid>", synopsis: "Rewritten while the project was open." });
```

```json
{
  "refused": "scrivener-open",
  "message": "The project contains Files/user.lock — Scrivener has it open (possibly on another machine). Close it there first, or pass force: true if you know the lock is stale."
}
```
